# Physics module demo scenes

Each folder holds one physics module's demo scenes, as its builder made and checked them (every goal met in the engine): the lesson
demos and worked examples that web/CONTRACT.md names for that module. Open one in the app (drag the .json onto the page) or run it with
`POST /api/simulate`. research/rw-validate-space-air.ts reads demos/space; nothing here is uploaded to Vercel (.vercelignore).
